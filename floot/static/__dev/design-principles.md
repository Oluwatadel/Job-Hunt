Editorial calm, not SaaS dashboard: a personal job-hunt log that reads like a well-kept notebook which happens to update itself live. Warm ivory paper ground throughout (never pure white/black). Distinctive thread: ledger-meets-letterpress — a serif display headline (Fraunces) paired with a quiet humanist sans body (Inter Tight) and a tabular mono (JetBrains Mono) reserved for every date, count and stat so the page's numbers always read as "data" against its prose-like headings. Status is conveyed by restrained duotone chips (a soft tint plus one saturated ink, never a loud solid block) so the page feels hand-tended rather than automated. Both light and dark mode supported, tokens fully redefined in .dark. Pacing register: tight/compact (dashboard-tool, not landing-page spacious) — dense stat strip, compact cards, generous only around page margins. Hairline borders only (1px, warm-tinted neutral, never gray/black) carry the cards; shadows are a faint warm-tinted lift used only on hover/popovers/dialogs, never as a resting card style. Soft radii (12-16px on cards, pill/full on chips and badges). Single accent: a deep forest green, used sparingly — primary buttons, active filter state, the live-connection pulse dot — never more than one saturated accent hue on screen at once; status colors are distinct per status but kept muted/desaturated so they never compete with the accent. Icons: lucide-react only, thin stroke weight, never filled. Motion: short and quiet (150-200ms ease-out) — a card appearing, a filter toggling, the live pulse — no bouncy or decorative animation.
